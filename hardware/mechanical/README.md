# Mechanical Hardware – Enclosure

## Overview

The enclosure houses the Seeed XIAO ESP32-S3, breadboard, ULN2003 driver board,
and stepper motor in a compact, accessible box.

## Contents

| File / Folder | Description |
|---------------|-------------|
| `enclosure_notes.md` | Design requirements and fabrication notes |
| `assembly_guide.md` | Step-by-step assembly instructions |

## Design Constraints

| Constraint | Value |
|-----------|-------|
| Internal volume (min) | 180 mm × 80 mm × 50 mm |
| Material | PLA (3-D printed) or laser-cut acrylic |
| Ventilation | Minimum two 10 mm slots for airflow |
| Access | Removable lid with M3 screws |
| Cable entry | USB-C slot on one wall |
| Motor mount | 28BYJ-48 standard 35 mm bolt circle |
